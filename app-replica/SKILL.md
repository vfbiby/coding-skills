# App 复刻

把目标 App 转成有版本、有证据、可执行的复刻合同，再逐页面状态实现。工具候选和未经验证的步骤标为待验证；流程成熟度由实战证据决定。

## 母本与范围

确认平台、App 版本/build、设备、OS、语言、主题、文字大小和显示缩放。截图记录物理像素尺寸；布局记录逻辑单位、缩放比例与安全区，坐标换算以实测为准。

建立页面 × 状态清单及导航路径，本轮选择可完成闭环的切片。保留差异须引用当前任务中的用户要求或明确适用的产品决议；旧实现只作线索。用户要求保留的功能也须逐状态验收。未采到的行为标为待采，未实现的行为标为差异。

## 采样

先探测设备访问、截图和 UI 树能力。iOS 读 [iOS 采样参考](references/ios.md)；其他平台按现场工具能力选路径。

采集截图及控件名称、类型、矩形和状态。树中缺失的颜色、字体、自绘内容用截图测量或手势实验补充，标注「控件实测」「截图测量」「推断」「未覆盖」。

已有 Appium 会话可用 [capture_ios.py](scripts/capture_ios.py) 保存当前截图、UI 树与矩形；用 --bundle-id 校验母本归属。逐状态保存全屏图、必要裁切、原始 UI 树（可获取时）、操作步骤和采样环境。含账户信息的原始材料按所有者指定位置保存，提交版脱敏且标出区域。采样限于导航和展示状态；提交订单、平仓、删除账户等业务写入须有对应授权。

交互采到后继状态：如编辑的未选、单选、全选、取消及删除就绪；排序核对上移、下移及松手后的顺序。记录前置状态 → 动作 → 可见结果，逐状态验证图标语义。可采删除入口而不提交，执行结果保持待验。

按本轮交互补采隐蔽状态：短/长列表两端拖动的按住与松手，区分弹性回弹和刷新；新增、移除再添加、排序后新增的位置与重启后的顺序；搜索的多层目录、输入、清空、根/祖先返回及键盘变化。

屏幕矩阵按布局形态选择主基准、较小/较大设备及适用的横屏、平板。记录压缩顺序、键盘遮挡与安全区行为。

## 实现与验收

每个切片产出环境清单、页面状态清单、几何与表面合同、token JSON、交互合同和截图证据。数值附证据路径、来源类型、单位、容差；token JSON 必须可解析。截图不能唯一确定的字体属性保留候选与不确定性。

静态截图等待布局与动画稳定后采集；按住等过渡状态明确标注。构建通过后仍检查运行时图标、文字和原生控件的显示。

将本轮差异编号，逐条追溯母本条目。按同一操作序列截图对照实现：控件位置、选择状态、工具栏变化（含图标/文字/背景颜色）及返回/手势结果。能进入页面只证明入口可用；本轮状态与转换全部有结果证据或明确待验，才报告覆盖情况。

对比前确认双方平台、屏幕、主题、语言和状态一致。动态文字只遮罩明确区域并记录原因；遮罩区仍需独立检查位置和语义。图表逐像素验收要求相同数据、时间区间和视口；条件不满足时只验外框、轴、样式及可对齐内容。字体抗锯齿等差异使用局部容差，避免全图平均值掩盖小控件缺陷。

主基准通过后按约定设备矩阵复核。报告已通过、保留差异和未覆盖三类；证据不足保持待验收。

## 流程沉淀

每个闭环后只把实测可复用步骤与失败教训回写技能。项目版本、设备、页面数值和业务决议留在项目档案；技能保留通用决策规则。重复且确定的步骤再提取脚本，并运行验证。流程完成以实际采样、实现和验收证据为准。
